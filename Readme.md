I am a third-year Bachelor of Computer Applications (BCA) student at Eternal University, building scalable full-stack web applications and exploring AI-powered tools and autonomous agents.

My practical experience includes engineering responsive SaaS portal modules and authentication systems at **Neximprove**, developing decoupled full-stack e-commerce architectures at **Axemata Modas**, and contributing to global open source in **GirlScript Summer of Code 2026 (Global Rank #1,493)**. ## Featured Projects

### 1. GitFix &mdash; AI Git &amp; GitHub Diagnostic Assistant
> **Developer Tool &bull; AI Agent &bull; Debugging Automation**

- **Problem:** Developers often encounter cryptic Git errors (merge conflicts, detached HEAD states, rebase issues) where running incorrect commands can cause irreversible loss of committed work.
- **Solution:** An AI agent that analyzes raw terminal error logs, identifies root causes in plain language, and generates step-by-step resolution commands with explicit warnings before potentially destructive operations.
- **Technologies:** Smartly Labs, AI Agent Architecture, Developer Tooling, Git CLI Diagnostics
- **Links:** [Launch Live Agent](https://infra.smartlylabs.ai/agents/cmt7498fv00030ai20hy3qwzg/chat)

---

### 2. Internship Researcher &mdash; Automated Career Intelligence Agent
> **Career Automation &bull; Web Scraping &bull; AI Research**

- **Problem:** Finding legitimate, active internship openings across disparate job boards and corporate portals is time-consuming and often surfaced with outdated deadlines.
- **Solution:** An autonomous research agent built on Smartly Labs that searches official career portals by field, role, and location preferences, extracting verified eligibility criteria, compensation/stipend details, application deadlines, and direct apply links.
- **Technologies:** Smartly Labs, AI Agent Workflows, Automation, Structured Web Research
- **Links:** [Launch Live Agent](https://infra.smartlylabs.ai/agents/cmsn2q2je000z04lhwzl2q7ai/chat)

---

### 3. Resume Analyzer &mdash; AI Career Evaluation Platform
> **Career Platform &bull; ATS Optimization &bull; Frontend Analytics**

- **Problem:** Job applicants frequently struggle to identify ATS formatting discrepancies and keyword misalignments before submitting resumes to enterprise applicant tracking systems.
- **Solution:** A React-based document evaluation platform that evaluates resume structure, computes scoring metrics, and provides actionable keyword matching recommendations through an interactive preview dashboard.
- **Technologies:** React.js, Tailwind CSS, REST APIs, Vercel
- **Links:** [Live Demo](https://ai-career-platform-delta.vercel.app/) &bull; [Source Code](https://github.com/24-Harshdeep/ai-career-platform)

---

### 4. ZaikaHub &mdash; Recipe Discovery Web Platform
> **Web Application &bull; REST API Integration &bull; Responsive Design**

- **Problem:** Users need a fast, intuitive way to search, filter, and explore curated culinary recipes without heavy page reloads.
- **Solution:** A responsive culinary exploration platform built with React and Tailwind CSS, featuring client-side dynamic routing via React Router, external API data fetching, and an adaptive multi-device layout.
- **Technologies:** React.js, React Router, REST APIs, Tailwind CSS, Netlify
- **Links:** [Live Demo](https://zaikahubb.netlify.app/) &bull; [Source Code](https://github.com/24-Harshdeep/Zaikahub)

---

### 5. Adaptive Chatbot &mdash; Full-Stack Conversational AI
> **Full-Stack Application &bull; Session Persistence &bull; Backend Routing**

- **Problem:** Lightweight chat interfaces frequently fail to persist conversation context across page reloads or maintain structured user interaction records.
- **Solution:** A full-stack conversational web application featuring custom Express.js REST API routes, real-time message state rendering in React, and persistent MongoDB document models for session and message history tracking.
- **Technologies:** React.js, Node.js, Express.js, MongoDB Atlas, REST APIs
- **Links:** [Live Demo](https://chatbot-frontend-3f4it92se-24-harshdeeps-projects.vercel.app/) &bull; [Source Code](https://github.com/24-Harshdeep/ChatBot-FullStack-)
